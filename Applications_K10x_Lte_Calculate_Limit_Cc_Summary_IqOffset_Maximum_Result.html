# CALCulate<n>:LIMit<li>[:CC<cc>]:SUMMary:IQOFfset:MAXimum:RESult
value: str = driver.applications.k10Xlte.calculate.limit.cc.summary.iqOffset.maximum.result.get(window = repcap.Window.Default, limitIx = repcap.LimitIx.Default, carrierComponent = repcap.CarrierComponent.Default)

Queries the result of the I/Q offset limit check.

Parameters:

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

  • limitIx – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Limit’)

  • carrierComponent – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Cc’)

Returns:

limit_check: The type of limit (average or maximum) that is queried depends on the last syntax element.

  • FAILED: Limit check has failed.

  • PASSED: Limit check has passed.

  • NOTEVALUATED: Limits have not been evaluated.

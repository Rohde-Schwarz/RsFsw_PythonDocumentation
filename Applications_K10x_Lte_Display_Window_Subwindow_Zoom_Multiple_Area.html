# DISPlay[:WINDow<n>][:SUBWindow<w>]:ZOOM:MULTiple<zn>:AREA
# get:
value: AreaStruct = driver.applications.k10Xlte.display.window.subwindow.zoom.multiple.area.get(window = repcap.Window.Default, subWindow = repcap.SubWindow.Default, zoomWindow = repcap.ZoomWindow.Default)
# set:
driver.applications.k10Xlte.display.window.subwindow.zoom.multiple.area.set(x_1 = 1.0, y_1 = 1.0, x_2 = 1.0, y_2 = 1.0, window = repcap.Window.Default, subWindow = repcap.SubWindow.Default, zoomWindow = repcap.ZoomWindow.Default)

Defines the zoom area for a multiple zoom. To define a zoom area, you first have to turn the zoom on.

Parameters:

  • x_1 – Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

  • y_1 – Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

  • x_2 – Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

  • y_2 – Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Window’)

  • subWindow – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Subwindow’)

  • zoomWindow – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Multiple’)

Returns:

structure: for return value, see the help for AreaStruct structure arguments.

class AreaStruct

Response structure. Fields:

  • 1 X_1: float: Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

  • 2 Y_1: float: Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

  • 3 X_2: float: Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

  • 4 Y_2: float: Diagram coordinates in % of the complete diagram that define the zoom area. The lower left corner is the origin of coordinate system. The upper right corner is the end point of the system.

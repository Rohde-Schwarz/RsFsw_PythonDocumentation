# CALCulate<n>:CHRDetection:TABLe:RESults
value: GetStruct = driver.applications.k60Transient.calculate.chrDetection.table.results.get(start = 1, end = 1, window = repcap.Window.Default)

Queries the chirp results table. The result is a comma-separated list of value sets, one set for each chirp. If no query parameters are specified, the results for all detected chirps are returned. Which values are returned depends on the enabled parameters for the results tables (see method RsFsw.applications.k60Transient.calculate.chrDetection.table.column.set() ) .

Parameters:

  • start – The chirp number of the first chirp to be returned. Chirp numbers start at 1.

  • end – The chirp number of the last chirp to be returned.

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

Returns:

structure: for return value, see the help for GetStruct structure arguments.

class GetStruct

Response structure. Fields:

  • 1 Idn: str: Timestamp which corresponds to the absolute time the beginning of the chirp was detected

  • 2 Chirp_No: float: Consecutive number of detected chirp, starts at 1 for each new measurement

  • 3 State_Index: float: Consecutive number of corresponding nominal chirp state as defined in the Chirp States table (see method RsFsw.applications.k60Transient.calculate.chrDetection.states.data.set() )

  • 4 Begin: str: Time offset from the analysis region start at which the signal first enters the tolerance area of a nominal chirp

  • 5 Length: str: The duration of a chirp from begin to end, that is, the time the signal remains in the tolerance area of a nominal chirp.

  • 6 Crate: str: Derivative of the FM vs time trace within the frequency measurement range

  • 7 Crate_Dev: float: Deviation of the detected chirp rate from the nominal chirp state (in kHz/us) . For details see ‘Chirp State Deviation’.

  • 8 Freq_Avg: float: Average frequency measured within the frequency measurement range of the chirp

  • 9 Fm_Dev_Max: float: Maximum deviation of the chirp frequency from the nominal chirp frequency as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see ‘Frequency Deviation (Peak) ‘.

  • 10 Fm_Dev_Rms: float: RMS deviation of the chirp frequency from the nominal (linear) chirp frequency as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see ‘Frequency Deviation (RMS) ‘.

  • 11 Fm_Dev_Avg: float: Average deviation of the chirp frequency from the nominal (linear) chirp frequency as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see ‘Frequency Deviation (Average) ‘.

  • 12 Pm_Dev_Max: float: Maximum deviation of the chirp phase from the nominal chirp phase as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see ‘Phase Deviation (Peak) ‘.

  • 13 Pm_Dev_Rms: float: RMS deviation of the chirp phase from the nominal (linear) chirp phase as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see ‘Phase Deviation (RMS) ‘.

  • 14 Pm_Dev_Avg: float: Average deviation of the chirp phase from the nominal (linear) chirp phase as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see ‘Phase Deviation (Average) ‘.

  • 15 Pow_Min: float: Minimum power level measured during a chirp. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

  • 16 Pow_Max: float: Maximum power level measured during a chirp. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

  • 17 Pow_Avg: float: Average power level measured during a chirp. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

  • 18 Pow_Rip: float: Power level measured during the chirp ripple time. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

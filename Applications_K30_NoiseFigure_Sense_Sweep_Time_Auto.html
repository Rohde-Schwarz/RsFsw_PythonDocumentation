# [SENSe]:SWEep:TIME:AUTO
# get:
value: bool = driver.applications.k30NoiseFigure.sense.sweep.time.auto.get()
# set:
driver.applications.k30NoiseFigure.sense.sweep.time.auto.set(state = False)

If enabled, the capture time is determined according to the set statistic count with the objective of getting a fast measurement. If disabled, the capture time must be defined manually using method RsFsw.sense.sweep.time.set() . Tip: In order to improve the measurement speed further by using short capture times, consider the following:

  • Use an external trigger which indicates the frame start. In this case, the minimum allowed capture time is reduced from 10 ms to 866 us (see method RsFsw.applications.k91Wlan.trigger.sequence.source.set() )

  • Measure only slots at the beginning of the frame, directly after the trigger (see ‘Slot scope’)

  • Use a small statistic count (see method RsFsw.applications.k10Xlte.sense.sweep.count.set() )

Parameters:

state – ON | OFF | 1 | 0

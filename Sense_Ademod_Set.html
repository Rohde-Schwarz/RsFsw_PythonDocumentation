driver.sense.ademod.set.set(structure)

Configures the analog demodulator of the instrument.

Parameters:

structure – for set value, see the help for SetStruct structure arguments.

Returns:

structure: for return value, see the help for SetStruct structure arguments.

class SetStruct

Structure for setting input parameters. Fields:

  • 1 Sample_Rate: float:

  • numeric value: The frequency at which measurement values are taken from the A/D-converter and stored in I/Q memory.Allowed range: refer to ‘Sample rate and demodulation bandwidth’.

  • 2 Record_Length: float: Number of samples to be stored in I/Q memory.

  • 3 Trigger_Source: enums.TriggerSourceB: Selection of the trigger source to use for the demodulator. For details on trigger sources see ‘Trigger Source’.

  • 4 Trigger_Slope: enums.SlopeType: Used slope of the trigger signal. The value indicated here will be ignored for trigger source = IMMediate.

  • 5 Offset_Samples: float: Number of samples to be used as an offset to the trigger signal. For details refer to ‘Sample rate and demodulation bandwidth’. The value indicated here is ignored for trigger source = IMMediate.

  • 6 No_Of_Meas: float: Number of repetitions of the measurement to be executed. The value indicated here is especially necessary for the average/maxhold/minhold function.

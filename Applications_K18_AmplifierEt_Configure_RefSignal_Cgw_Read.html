# CONFigure:REFSignal:CGW:READ
# set:
driver.applications.k18AmplifierEt.configure.refSignal.cgw.read.set()
# set_with_opc:
driver.applications.k18AmplifierEt.configure.refSignal.cgw.read.set_with_opc(opc_timeout_ms = 3000)

This command transfers a reference signal designed on a signal generator into the R&S FSW-K18.

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

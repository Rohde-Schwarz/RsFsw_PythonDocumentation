Defines the specific demodulation order for QAM.

Parameters:

qam_format – NORMal | DIFFerential | NPI4 | MNPi4

  • NORMal: Demodulation order QAM is used.

  • DIFFerential: Demodulation order DQAM is used.

  • NPI4: Demodulation order π/4-16QAM is used.

  • MNPI4: Demodulation order -π/4-32QAM is used.

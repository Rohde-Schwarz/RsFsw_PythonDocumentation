# [SENSe]:PULSe:POWer:MIN:AVERage
value: str = driver.applications.k6Pulse.sense.pulse.power.min.average.get(query_range = enums.SelectionRangeB.ALL)

Returns the statistical value for the minimum transmission power over the specified pulses.

Parameters:

query_range – CURRent | ALL

  • CURRent: Detected pulses in the current capture buffer

  • ALL: All detected pulses in the entire measurement.

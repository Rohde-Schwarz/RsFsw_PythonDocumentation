Immediate#

SCPI Command :

CALCulate<n>:LIMit<li>:CLEar[:IMMediate]
Commands in total: 1
Subgroups: 0
Direct child commands: 1
perform ( window=Window.Default, limitIx=LimitIx.Default ) → None
perform_with_opc ( window=Window.Default, limitIx=LimitIx.Default, opc_timeout_ms: int = -1 ) → None
# CALCulate<n>:LIMit<li>:CLEar[:IMMediate]
driver.applications.k10Xlte.calculate.limit.clear.immediate.perform(window = repcap.Window.Default, limitIx = repcap.LimitIx.Default)
driver.applications.k10Xlte.calculate.limit.clear.immediate.perform_with_opc(window = repcap.Window.Default, limitIx = repcap.LimitIx.Default, opc_timeout_ms = 3000)

Deletes the result of the current limit check. The command works on all limit lines in all measurement windows at the same time.

perform_with_opc() does the same as perform(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

  • limitIx – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Limit’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

IqPower#

SCPI Command :

TRIGger[:SEQuence]:LEVel<ant>:IQPower
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( instrument=Instrument.Default ) → float
set ( level: float, instrument=Instrument.Default ) → None
# TRIGger[:SEQuence]:LEVel<ant>:IQPower
# get:
value: float = driver.applications.k10Xlte.trigger.sequence.level.iqPower.get(instrument = repcap.Instrument.Default)
# set:
driver.applications.k10Xlte.trigger.sequence.level.iqPower.set(level = 1.0, instrument = repcap.Instrument.Default)

Defines the magnitude the I/Q data must exceed to cause a trigger event. Note that any RF attenuation or preamplification is considered when the trigger level is analyzed. If defined, a reference level offset is also considered.

Parameters:

  • level – numeric value

  • instrument – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Level’)

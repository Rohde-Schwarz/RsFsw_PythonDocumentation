# [SENSe]:DDEMod:SEARch:SYNC:NSTate
# get:
value: float = driver.applications.k70Vsa.sense.ddemod.search.sync.nstate.get()
# set:
driver.applications.k70Vsa.sense.ddemod.search.sync.nstate.set(nstate = 1.0)

Selects the degree of modulation (number of permitted states) . The pattern must have been selected before using method RsFsw.applications.k70Vsa.sense.ddemod.search.sync.name.set() . The number of permitted states depends on the modulation mode.

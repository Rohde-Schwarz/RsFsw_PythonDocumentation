# CALCulate<n>:LIMit<li>:ACPower:GAP<gap>:ACLR:RESult:ABSolute
value: str = driver.applications.k14Xnr5G.calculate.limit.acPower.gap.aclr.result.absolute.get(window = repcap.Window.Default, limitIx = repcap.LimitIx.Default, gapChannel = repcap.GapChannel.Default)

Queries the absolute power limit check results for the gap channels (MC ACLR measurements) . Prerequisites for this command

  • Select absolute limit check mode evaluation mode ACLR: CALCulate<n>:LIMit:ACPower:PMODe. Combined measurements: method RsFsw.applications.k14Xnr5G.sense.nr5G.acPower.alpMode.set()

Parameters:

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

  • limitIx – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Limit’)

  • gapChannel – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Gap’)

Returns:

limit_check: Returns two values, one for the upper and one for the lower adjacent channel.

  • PASSED: Limit check has passed.

  • FAILED: Limit check has failed.

# [SENSe]:BWIDth[:RESolution]
value: float = driver.applications.k149Uwb.sense.bandwidth.resolution.get()

Defines the resolution bandwidth and decouples the resolution bandwidth from the span. The 6 MHz Gaussian filter is provided for special measurements, such as 5G NR spurious emissions measurements. It is only available if you enter the value manually, not using the BAND:RES MAX command. It is not supported by all applications.

# LAYout:REPLace[:WINDow]
driver.applications.k70Vsa.layout.replace.window.set(window_name = 'abc', window_type = enums.WindowTypeK70.CaptureBufferMagnAbs=CBUFfer)

Replaces the window type (for example from Diagram to Result Summary) of an already existing window in the active channel while keeping its position, index and window name. To add a new window, use the method RsFsw.layout.add.window.get() command.

Parameters:

  • window_name – String containing the name of the existing window. By default, the name of a window is the same as its index. To determine the name and index of all active windows in the active channel, use the method RsFsw.layout.catalog.window.get() query.

  • window_type – (enum or string) Type of result display you want to use in the existing window. See method RsFsw.layout.add.window.get() for a list of available window types.

driver.applications.k14Xnr5G.configure.nr5G.uplink.cc.frame.copy_with_opc(carrierComponent = repcap.CarrierComponent.Default, frame = repcap.Frame.Default, opc_timeout_ms = 3000)

Copies a frame configuration.

copy_with_opc() does the same as copy(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

  • carrierComponent – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Cc’)

  • frame – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Frame’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

driver.applications.k149Uwb.sense.evaluation.filterPy.delete_with_opc(filterPy = repcap.FilterPy.Default, opc_timeout_ms = 3000)

Deletes the specified packet filter.

delete_with_opc() does the same as delete(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

  • filterPy – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘FilterPy’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

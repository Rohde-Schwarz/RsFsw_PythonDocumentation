# CALCulate<n>:LIMit<li>:BURSt:TFALl[:AVERage]:RESult
value: enums.CheckResult = driver.applications.k91Wlan.calculate.limit.burst.tfall.average.result.get(window = repcap.Window.Default, limitIx = repcap.LimitIx.Default)

Returns the result of the average or maximum fall time limit check. The limit value is defined by the standard or the user (see method RsFsw.applications.k91Wlan.calculate.limit.burst.tfall.maximum.set() ) . Is only available for IEEE 802.11b.

Parameters:

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

  • limitIx – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Limit’)

Returns:

result: PASS | FAILed

  • PASS: The defined limit for the parameter was not exceeded.

  • FAILED: The defined limit for the parameter was exceeded.

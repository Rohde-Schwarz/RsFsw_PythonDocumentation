# CALibration:MCGD:STATe
value: bool = driver.applications.k17Mcgd.calibration.mcgd.state.get()

Queries the calibration status of the Multi-Carrier Group Delay application.

Returns:

state:

  • ON | 1: Calibration has been performed, reference data is available.

  • OFF | 0: Calibration has not yet been performed or is currently running, reference data is not yet available.

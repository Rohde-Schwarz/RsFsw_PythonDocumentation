# INPut:ATTenuation:PROTection:RESet
driver.inputPy.attenuation.protection.reset(device_name = 'abc')

Resets the attenuator and reconnects the RF input with the input mixer for the FSW after an overload condition occurred and the protection mechanism intervened. The error status bit (bit 3 in the method RsFsw.status.questionable.power.event.get() status register) and the INPUT OVLD message in the status bar are cleared. (For details on the status register see the FSW base unit user manual) . The command works only if the overload condition has been eliminated first.

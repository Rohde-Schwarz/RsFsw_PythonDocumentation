Update#

SCPI Command :

CONFigure:DPD:UPDate
Commands in total: 3
Subgroups: 2
Direct child commands: 1
set ( ) → None
set_with_opc ( opc_timeout_ms: int = -1 ) → None
# CONFigure:DPD:UPDate
# set:
driver.applications.k18AmplifierEt.configure.dpd.update.set()
# set_with_opc:
driver.applications.k18AmplifierEt.configure.dpd.update.set_with_opc(opc_timeout_ms = 3000)

This command updates the DPD shaping tables on the R&S SMW when new measurement data is available. Prerequisites for this command

  • Turn on polynomial DPD (CONFigure:DDPD[:STATe]) .

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

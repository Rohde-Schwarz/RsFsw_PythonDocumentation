Selects the base station type.

Parameters:

bs_type –

  • FR1C: Base station for conducted requirements.

  • FR1H: Base station for hybrid requirements.

  • FR1O: Base station for over-the-air requirements in FR1.(Only for ACLR and SEM measurements.)

  • FR2O: Base station for over-the-air requirements in FR2.(Only for ACLR and SEM measurements.)

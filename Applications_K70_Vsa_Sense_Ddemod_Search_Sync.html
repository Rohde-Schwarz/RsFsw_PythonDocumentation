# [SENSe]:DDEMod:SEARch:SYNC:DELete
driver.applications.k70Vsa.sense.ddemod.search.sync.delete()
driver.applications.k70Vsa.sense.ddemod.search.sync.delete_with_opc(opc_timeout_ms = 3000)

Deletes a sync sequence. The sync sequence to be deleted must have been selected before using method RsFsw.applications.k70Vsa.sense.ddemod.search.sync.name.set() .

delete_with_opc() does the same as delete(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

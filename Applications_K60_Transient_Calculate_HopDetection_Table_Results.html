# CALCulate<n>:HOPDetection:TABLe:RESults
value: GetStruct = driver.applications.k60Transient.calculate.hopDetection.table.results.get(start = 1, end = 1, window = repcap.Window.Default)

Queries the hop results table. The result is a comma-separated list of value sets, one set for each hop. If no query parameters are specified, the results for all detected hops are returned. Which values are returned depends on the enabled parameters for the results tables (see method RsFsw.applications.k60Transient.calculate.hopDetection.table.column.set() ) .

Parameters:

  • start – The hop number of the first hop to be returned. Hop numbers start at 1.

  • end – The hop number of the last hop to be returned.

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

Returns:

structure: for return value, see the help for GetStruct structure arguments.

class GetStruct

Response structure. Fields:

  • 1 Idn: str: timestamp which corresponds to the absolute time the beginning of the hop was detected

  • 2 Hop_No: float: consecutive number of detected hop, starts at 1 for each new measurement

  • 3 State_Index: float: consecutive number of corresponding nominal hop state as defined in the hop States table (see method RsFsw.applications.k60Transient.calculate.hopDetection.states.data.set() )

  • 4 Begin: str: relative time (in ms) from the capture start at which the signal first enters the tolerance area of a nominal hop (within the analysis region)

  • 5 Dwell_Time: str: The duration of a hop from begin to end, that is, the time the signal remains in the tolerance area of a nominal hop frequency.

  • 6 Switch_Time: str: The time the signal requires to ‘hop’ from one level to the next. It is defined as the time between a hop end and the following hop begin.

  • 7 Freq_Nom: float: Nominal frequency of the hop state

  • 8 Freq_Avg: float: Average frequency measured within the frequency measurement range of the hop

  • 9 Freq_Dev: float: Deviation of the hop frequency from the nominal hop state frequency For details see ‘Hop State Deviation’.

  • 10 Freq_Rel: float: Relative difference in frequency between two hops. For details see ‘Relative Frequency (Hop-to-Hop) ‘.

  • 11 Fm_Dev_Max: float: Maximum deviation of the hop frequency from the nominal hop frequency as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see ‘Frequency Deviation (Peak) ‘.

  • 12 Fm_Dev_Rms: float: RMS deviation of the hop frequency from the nominal (linear) hop frequency as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see ‘Frequency Deviation (RMS) ‘.

  • 13 Fm_Dev_Avg: float: Average deviation of the hop frequency from the nominal (linear) hop frequency as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see ‘Frequency Deviation (Average) ‘.

  • 14 Pm_Dev_Max: float: Maximum deviation of the hop phase from the nominal hop phase as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see ‘Phase Deviation (Peak) ‘.

  • 15 Pm_Dev_Rms: float: RMS deviation of the hop phase from the nominal (linear) hop phase as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see ‘Phase Deviation (RMS) ‘.

  • 16 Pm_Dev_Avg: float: Average deviation of the hop phase from the nominal (linear) hop phase as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see ‘Phase Deviation (Average) ‘.

  • 17 Pow_Min: float: Minimum power level measured during a hop. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

  • 18 Pow_Max: float: Maximum power level measured during a hop. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

  • 19 Pow_Avg: float: Average power level measured during a hop. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

  • 20 Pow_Rip: float: Power level measured during the hop ripple time. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

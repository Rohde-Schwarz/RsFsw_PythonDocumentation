# FORMat:DEXPort:DSEParator
# get:
value: enums.Separator = driver.applications.k40PhaseNoise.formatPy.dexport.dseparator.get()
# set:
driver.applications.k40PhaseNoise.formatPy.dexport.dseparator.set(separator = enums.Separator.COMMa)

Selects the decimal separator for data exported in ASCII format.

Parameters:

separator – POINt | COMMa

  • COMMa: Uses a comma as decimal separator, e.g. 4,05.

  • POINt: Uses a point as decimal separator, e.g. 4.05.

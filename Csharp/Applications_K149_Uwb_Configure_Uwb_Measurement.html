// SCPI: CONFigure[:UWB]:MEASurement
// Get:
SweepModeBenum value = driver.Applications.K149_Uwb.Configure.Uwb.Measurement.Get();
// Set:
driver.Applications.K149_Uwb.Configure.Uwb.Measurement.Set(SweepModeBenum.AUTO);

This command selects the measurement to be performed in the GSM application. Note: if you switch between the IQ measurement and MCWN measurement, the enable, positive and negative transition settings in the status registers are set to their default values. Thus, you must reconfigure the transitions after switching measurements, if necessary. (See “Querying the status registers”) .

mode IQ | MCWNoise

  • IQ: Default I/Q measurement to determine the modulation accuracy, modulation /transient spectrum, trigger parameters etc.

  • MCWNoise: Sweep measurement to determine noise and intermodulation in multicarrier setups.

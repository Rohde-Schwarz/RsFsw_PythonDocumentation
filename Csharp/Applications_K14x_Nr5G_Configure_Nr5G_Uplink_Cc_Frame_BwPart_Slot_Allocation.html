Copies a PUSCH configuration to other slots. Prerequisites for this command

  • Number of configurable slots > 1 (CONFigure[:NR5G]:UL[:CC<cc>]:FRAMe<fr>:BWPart<bwp>:CSLot) .

  • Select paste mode (CONFigure[:NR5G]:UL[:CC<cc>]:FRAMe<fr>:BWPart<bwp>:SLOT<sl>:ALLocation<al>:COPY:MODE) .

carrierComponent Repeated capability selector

frame Repeated capability selector

bwPart Repeated capability selector

slotRc Repeated capability selector

allocation Repeated capability selector

CopyToAndWait is the same as CopyTo, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

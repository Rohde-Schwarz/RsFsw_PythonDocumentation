Defines the number of sweeps that the application uses to average traces. (For Pulse measurements, see also ) . In continuous sweep mode, the application calculates the moving average over the average count. In single sweep mode, the application stops the measurement and calculates the average after the average count has been reached.

count If you set a sweep count of 0 or 1, the application performs one single sweep in single sweep mode. In continuous sweep mode, if the average count is set to 0, a moving average over 10 sweeps is performed.

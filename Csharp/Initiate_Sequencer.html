// SCPI: INITiate:SEQuencer:ABORt
driver.Initiate.Sequencer.Abort();
driver.Initiate.Sequencer.AbortAndWait();
driver.Initiate.Sequencer.AbortAndWait(1000);

Stops the currently active sequence of measurements. You can start a new sequence any time using method RsFsw.Initiate.Sequencer.Immediate.Perform.

AbortAndWait is the same as Abort, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

driver.Applications.K6_Pulse.Calculate.Trend.Phase.Y.Set(PulsePhaseItemsEnum.DEViation, WindowRepCap.Default);
driver.Applications.K6_Pulse.Calculate.Trend.Phase.Y.Set(PulsePhaseItemsEnum.DEViation);

Configures the y-axis of the Parameter Trend result display. The x-axis is configured using the CALCulate<n>:TRENd:<GroupName>:X commands.

yaxis Pulse parameter to be displayed on the y-axis. For a description of the available parameters see “Phase parameters”.

  • POINt: Pulse phase at measurement point

  • PPPHase: Pulse-Pulse Phase Difference

  • RERRor: Phase Error (RMS)

  • PERRor: Phase Error (Peak)

  • DEViation: Phase Deviation

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

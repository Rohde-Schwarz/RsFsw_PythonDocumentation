Defines the format of the input signal.

type IQ | I | Q

  • IQ: The input signal is filtered and resampled to the sample rate of the application.Two input channels are required for each input signal, one for the in-phase component, and one for the quadrature component.

  • I: The in-phase component of the input signal is filtered and resampled to the sample rate of the application. If the center frequency is not 0, the in-phase component of the input signal is down-converted first (Low IF I) .

  • Q: The quadrature component of the input signal is filtered and resampled to the sample rate of the application. If the center frequency is not 0, the quadrature component of the input signal is down-converted first (Low IF Q) .

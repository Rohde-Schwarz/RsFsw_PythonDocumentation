Applications:K91Wlan:Fetch:ScDetailed:Evm:Data#

SCPI Commands

FETCh:SCDetailed:EVM:DATA

Direct SCPI Members

string Get ( )#
// SCPI: FETCh:SCDetailed:EVM:DATA
string value = driver.Applications.K91_Wlan.Fetch.ScDetailed.Evm.Data.Get();

Returns the EVM for all data subcarriers. The result is a comma-separated list of values, one for each PPDU, each RU, and each user. These results are only available if the Signal Content Detailed result display is currently active (see method RsFsw.Layout.Add.Window.Get) .

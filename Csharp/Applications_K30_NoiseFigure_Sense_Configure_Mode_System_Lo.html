Selects the type of local oscillator you are using. The command is available for measurements on frequency converting DUTs [SENSe:]CONFigure:MODE:DUT .

loType FIXed | VARiable

  • FIXed: The local oscillator is used as a fixed frequency source.The IF is variable.

  • VARiable: The local oscillator is used as a variable frequency source.The IF is fixed.

driver.Applications.K14x_Nr5G.Configure.Settings.Rf.SetAndWait(1000);

Downloads the RF settings (frequency, level) from the generator to the analyzer. Prerequisites for this command

  • IP connection to a signal generator.

  • Generator control state is on (CONFigure:GENerator:CONTrol[:STATe]) .

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

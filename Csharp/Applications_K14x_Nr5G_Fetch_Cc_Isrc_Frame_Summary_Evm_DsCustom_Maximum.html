Queries the EVM of all PDSCH resource elements with a custom modulation. Prerequisites for this command

  • Use custom constellation (CONFigure[:NR5G]:DL[:CC<cc>]:FRAMe<fr>:BWPart<bwp>:SLOT<sl>:ALLocation<al>:CUSTom:STATe) .

method RsFsw.Applications.K14Xnr5G.Fetch.All.Summary.Evm.Ds1K.Get queries the average result over all carriers. Prerequisites:

  • Select to evaluate all carriers ([SENSe:]NR5G:RSUMmary:CCResult) .

evm: EVM in % or dB.

result Available for combined measurements. Queries the EVM of all events (meas IDs) . Omitting this parameter queries the EVM of the selected event.

carrierComponent Repeated capability selector

frame Repeated capability selector

Sense:Ademod:Set#

SCPI Commands

[SENSe]:ADEMod:SET

Direct SCPI Members

class Set_Data

Structure for setting input parameters.

double SampleRate

  • numeric value: The frequency at which measurement values are taken from the A/D-converter and stored in I/Q memory.Allowed range: refer to &quot;Sample rate and demodulation bandwidth&quot;.

double RecordLength

Number of samples to be stored in I/Q memory.

TriggerSourceBenum TriggerSource

Selection of the trigger source to use for the demodulator. For details on trigger sources see &quot;Trigger Source&quot;.

SlopeTypeEnum TriggerSlope

Used slope of the trigger signal. The value indicated here will be ignored for trigger source = IMMediate.

double OffsetSamples

Number of samples to be used as an offset to the trigger signal. For details refer to &quot;Sample rate and demodulation bandwidth&quot;. The value indicated here is ignored for trigger source = IMMediate.

double NoOfMeas

Number of repetitions of the measurement to be executed. The value indicated here is especially necessary for the average/maxhold/minhold function.

Selects the marker step size mode for all markers in all windows. The step size defines the distance the marker moves when you move it with the rotary knob. It therefore takes effect in manual operation only.

  • STANdard: the marker moves from one pixel to the next

  • POINts: the marker moves from one sweep point to the next

window Repeated capability selector

marker Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

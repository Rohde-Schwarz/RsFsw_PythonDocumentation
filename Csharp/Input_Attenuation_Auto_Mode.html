// SCPI: INPut:ATTenuation:AUTO:MODE
// Get:
AttenuatorModeEnum value = driver.Input.Attenuation.Auto.Mode.Get();
// Set:
driver.Input.Attenuation.Auto.Mode.Set(AttenuatorModeEnum.LDIStortion);

Selects the priority for signal processing after the RF attenuation has been applied.

optMode LNOise | LDIStortion

  • LNOise: Optimized for high sensitivity and low noise levels

  • LDIStortion: Optimized for low distortion by avoiding intermodulation

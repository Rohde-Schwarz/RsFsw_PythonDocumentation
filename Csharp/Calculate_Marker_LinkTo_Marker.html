// Range: Nr1 .. Nr16
var rc = driver.Calculate.Marker.LinkTo.Marker.RepCapMarkerDestination;
driver.Calculate.Marker.LinkTo.Marker.RepCapMarkerDestination = MarkerDestinationRepCap.Nr1;

SCPI Commands

CALCulate<n>:MARKer<ms>:LINK:TO:MARKer<mt>

Cloning the Group

// Create a clone of the original group, that exists independently

void Set ( bool state )

// SCPI: CALCulate<n>:MARKer<ms>:LINK:TO:MARKer<mt>
driver.Calculate.Marker.LinkTo.Marker.Set(false, WindowRepCap.Default, MarkerRepCap.Default, MarkerDestinationRepCap.Default);
driver.Calculate.Marker.LinkTo.Marker.Set(false);

Links the normal source marker <ms> to any active destination marker <md> (normal or delta marker) . If you change the horizontal position of marker <md>, marker <ms> changes its horizontal position to the same value.

state ON | OFF | 0 | 1

  • OFF | 0: Switches the function off

  • ON | 1: Switches the function on

window Repeated capability selector

marker Repeated capability selector

markerDestination Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

Applications:K9X11Ad:Layout:Replace:Window#

SCPI Commands

LAYout:REPLace[:WINDow]

Direct SCPI Members

void Set ( string windowName, WindowTypeK9Xenum windowType )#
// SCPI: LAYout:REPLace[:WINDow]
driver.Applications.K9x_11ad.Layout.Replace.Window.Set("abc", WindowTypeK9Xenum.ChannelFreqResponse);

Replaces the window type (for example from Diagram to Result Summary) of an already existing window in the active channel while keeping its position, index and window name. To add a new window, use the method RsFsw.Layout.Add.Window.Get command.

windowName String containing the name of the existing window. By default, the name of a window is the same as its index. To determine the name and index of all active windows in the active channel, use the method RsFsw.Layout.Catalog.Window.Get() query.

windowType Type of result display you want to use in the existing window. See method RsFsw.Layout.Add.Window.Get() for a list of available window types.

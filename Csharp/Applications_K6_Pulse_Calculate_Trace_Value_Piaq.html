Defines which signal component (I/Q) is evaluated in which trace for the “Pulse I and Q” result display. By default, the I component is displayed by trace 1, while the Q component is displayed by trace 4. This setting is not available for any other results displays.

detector ITIMe | QTIMe

  • ITIMe: The I component is evaluated by the selected trace.

  • QTIMe: The Q component is evaluated by the selected trace.

window Repeated capability selector

trace Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

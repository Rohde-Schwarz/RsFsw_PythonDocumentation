// Set:
driver.Applications.K18_AmplifierEt.Configure.Sync.Domain.Set(SyncDomainEnum.IQDirect);

This command selects the synchronization method.

  • IQDirect: I/Q data for the reference signal is directly correlated with the reference and measured signal.

  • IQPDiff: Correlation on the phase differentiated I/Q data.

  • MAGNitude: Correlation on the magnitude of the I/Q data with no regard for phase information.

  • TRIGger: It is assumed that the capture is triggered at the start of the reference waveform.

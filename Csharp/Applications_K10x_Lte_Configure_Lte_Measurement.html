Applications:K10Xlte:Configure:Lte:Measurement#

SCPI Commands

CONFigure[:LTE]:MEASurement

Direct SCPI Members

MeasurementLteEnum Get ( )#
void Set ( MeasurementLteEnum measurement )#
// SCPI: CONFigure[:LTE]:MEASurement
// Get:
MeasurementLteEnum value = driver.Applications.K10x_Lte.Configure.Lte.Measurement.Get();
// Set:
driver.Applications.K10x_Lte.Configure.Lte.Measurement.Set(MeasurementLteEnum.ACLR);

Selects the measurement.

  • ACLR: Selects the Adjacent Channel Leakage Ratio measurement.

  • CACLr: Selects the Cumulative ACLR measurement.

  • ESPectrum: Selects the Spectrum Emission Mask measurement.

  • EVM: Selects I/Q measurements.

  • MCAClr: Selects Multi-Carrier ACLR measurement.

  • MCESpectrum: Selects Multi-Carrier SEM measurement.

  • TAERor: Selects the Time Alignment Error measurement.

  • TPOO: Selects the Transmit On/Off Power measurement.

Activates or deactivates a marker that defines a fixed reference point for relative marker analysis. If necessary, the command activates a marker and positions it on the peak power. Subsequently, you can change the coordinates of the fixed reference independent of the marker. The fixed reference is independent of the trace and is applied to all active delta markers.

state ON | OFF | 0 | 1

  • OFF | 0: Switches the function off

  • ON | 1: Switches the function on

window Repeated capability selector

deltaMarker Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

Select the numerical results to be displayed in the Spurious Detection Table. For a description of the individual results see “Spurious Detection Table”.

state ON | OFF | 0 | 1

  • OFF | 0: Hides the result

  • ON | 1: Displays the result

headers ALL | SID | STARt | STOP | RBW | FREQuency | POWer | DELTa | IDENt

  • ALL: All available results are displayed

  • STARt: Start frequency of range/span

  • STOP: Stop frequency of range/span

  • FREQuency: Spur frequency

  • POWer: Spur power

  • DELTa: Delta of spur to limit

  • RBW: Resolution bandwidth used for range

  • IDENt: Spur ID

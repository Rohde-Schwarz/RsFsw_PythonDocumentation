Selects a tab in diagrams with multiple subwindows (or views) . Note that selecting a tab does not actually select a subwindow. To select a subwindow, for example to query the results of a subwindow, use DISPlay[:WINDow<n>][:SUBWindow<w>]:SELect.

window Repeated capability selector

tab Repeated capability selector

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

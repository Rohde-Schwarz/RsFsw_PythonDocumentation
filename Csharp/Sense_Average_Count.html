Sense:Average:Count#

SCPI Commands

[SENSe]:AVERage:COUNt

Direct SCPI Members

double Get ( )#
void Set ( double averageCount )#
// SCPI: [SENSe]:AVERage:COUNt
// Get:
double value = driver.Sense.Average.Count.Get();
// Set:
driver.Sense.Average.Count.Set(1.0);

Defines the number of sweeps that the application uses to average traces. During calibration measurements, the phase and amplitude values are averaged over the defined number of sweeps. In case of continuous sweep mode, the application calculates the moving average over the average count. In case of single sweep mode, the application stops the measurement and calculates the average after the average count has been reached.

averageCount If you set an average count of 0 or 1, the application performs one single sweep in single sweep mode. In continuous sweep mode, if the average count is set to 0, a moving average over 10 sweeps is performed.

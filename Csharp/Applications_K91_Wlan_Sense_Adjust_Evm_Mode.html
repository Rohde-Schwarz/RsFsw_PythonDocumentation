Defines how the instrument determines the number of OFDM-symbols to consider during the EVM optimization measurement for the auto level function.

mode AUTO | MANual

  • AUTO: The R&S FSW WLAN application uses all OFDM symbols for the auto level EVM measurement.

  • MANual: Configure the number of OFDM-symbols the instrument should consider during the EVM measurement for the auto level function manually using [SENSe:]ADJust:EVM:SYMBols.

Deletes the selected user (station) from the HE Multi-User Downlink PPDU configuration table (for MIMO configuration only) .

segment Repeated capability selector

channel Repeated capability selector

ruAllocationIx Repeated capability selector

userIx Repeated capability selector

DeleteAndWait is the same as Delete, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

Defines an electronic attenuation manually. Automatic mode must be switched off (INP:EATT:AUTO OFF, see method RsFsw.Applications.K17Mcgd.Input.Eatt.Auto.Set) . If the current reference level is not compatible with an attenuation that has been set manually, the command also adjusts the reference level. Requires the electronic attenuation hardware option. Is not available if the optional Digital Baseband interface is active.

attenuation attenuation in dB

Applications:K60Transient:Calculate:HopDetection:Table:Results#

SCPI Commands

CALCulate<n>:HOPDetection:TABLe:RESults

Direct SCPI Members

class Get_Data

Response structure.

string Id

timestamp which corresponds to the absolute time the beginning of the hop was detected

double HopNo

consecutive number of detected hop, starts at 1 for each new measurement

double StateIndex

consecutive number of corresponding nominal hop state as defined in the hop States table (see method RsFsw.Applications.K60Transient.Calculate.HopDetection.States.Data.Set())

string Begin

relative time (in ms) from the capture start at which the signal first enters the tolerance area of a nominal hop (within the analysis region)

string DwellTime

The duration of a hop from begin to end, that is, the time the signal remains in the tolerance area of a nominal hop frequency.

string SwitchTime

The time the signal requires to &quot;hop&quot; from one level to the next. It is defined as the time between a hop end and the following hop begin.

double FreqNom

Nominal frequency of the hop state

double FreqAvg

Average frequency measured within the frequency measurement range of the hop

double FreqDev

Deviation of the hop frequency from the nominal hop state frequency For details see &quot;Hop State Deviation&quot;.

double FreqRel

Relative difference in frequency between two hops. For details see &quot;Relative Frequency (Hop-to-Hop) &quot;.

double FmDevMax

Maximum deviation of the hop frequency from the nominal hop frequency as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see &quot;Frequency Deviation (Peak) &quot;.

double FmDevRms

RMS deviation of the hop frequency from the nominal (linear) hop frequency as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see &quot;Frequency Deviation (RMS) &quot;.

double FmDevAvg

Average deviation of the hop frequency from the nominal (linear) hop frequency as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see &quot;Frequency Deviation (Average) &quot;.

double PmDevMax

Maximum deviation of the hop phase from the nominal hop phase as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see &quot;Phase Deviation (Peak) &quot;.

double PmDevRms

RMS deviation of the hop phase from the nominal (linear) hop phase as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see &quot;Phase Deviation (RMS) &quot;.

double PmDevAvg

Average deviation of the hop phase from the nominal (linear) hop phase as defined in the Hop States table. The deviation is calculated within the frequency measurement range of the hop. For details see &quot;Phase Deviation (Average) &quot;.

double PowMin

Minimum power level measured during a hop. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

double PowMax

Maximum power level measured during a hop. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

double PowAvg

Average power level measured during a hop. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

double PowRip

Power level measured during the hop ripple time. Which part of the hop precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

Queries the hop results table. The result is a comma-separated list of value sets, one set for each hop. If no query parameters are specified, the results for all detected hops are returned. Which values are returned depends on the enabled parameters for the results tables (see method RsFsw.Applications.K60Transient.Calculate.HopDetection.Table.Column.Set) .

For return value see the help for Get_Data structure arguments

start The hop number of the first hop to be returned. Hop numbers start at 1.

end The hop number of the last hop to be returned.

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

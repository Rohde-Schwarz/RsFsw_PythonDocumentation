When the reference level is adjusted automatically using the method RsFsw.Sense.Adjust.Level.Set command, the internal attenuators and the preamplifier are also adjusted. To avoid frequent adaptation due to small changes in the input signal, you can define a hysteresis. This setting defines an upper threshold the signal must exceed (compared to the last measurement) before the reference level is adapted automatically.

threshold 0 dB to 200 dB

Direct SCPI Members

void Recall ( )#
void RecallAndWait ( )#
void RecallAndWait ( int opcTimeoutMs )
// SCPI: [SENSe]:CORRection:RECall
driver.Sense.Correction.Recall();
driver.Sense.Correction.RecallAndWait();
driver.Sense.Correction.RecallAndWait(1000);

Restores the measurement configuration used for calibration. Is only available if External Generator Control (R&S FSW-B10) is installed and active.

RecallAndWait is the same as Recall, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

Determines which modulation type is used to demodulate the frame after to the last configured subframe. Is only available if the additional Multi-Modulation Analysis option (FSW-K70M) is installed.

modulation AUTO | DATA | PATTern

  • Data: The modulation type defined for data symbols is used (see [SENSe:]DDEMod:MAPPing[:VALue])

  • Pattern: The modulation type defined for pattern symbols is used (see [SENSe:]DDEMod:PATTern:MAPPing[:VALue]) .

  • Auto: The nextt frame uses the same modulation as the first subframe of the frame configuration.

Moves a delta marker to a particular coordinate on the x-axis. If necessary, the command activates the delta marker and positions a reference marker to the peak power.

stimulus Numeric value that defines the marker position on the x-axis. The position is relative to the reference marker. To select an absolute position you have to change the delta marker mode with method RsFsw.Calculate.DeltaMarker.Mode.Set(). A query returns the relative position of the delta marker.

window Repeated capability selector

deltaMarker Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

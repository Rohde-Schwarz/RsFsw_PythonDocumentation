Applications:K91Wlan:Calculate:Limit:AcPower:Achannel:Result#

SCPI Commands

CALCulate<n>:LIMit<li>:ACPower:ACHannel:RESult

Direct SCPI Members

class Get_Data

Response structure.

CheckResultEnum LowerAch

The state of the limit check for the lower alternate or adjacent channels.

  • PASSED: Limit check has passed.

  • FAIL: Limit check has failed.

CheckResultEnum UpperAch

The state of the limit check for the upper alternate or adjacent channels.

  • PASSED: Limit check has passed.

  • FAIL: Limit check has failed.

Get_Data Get ( )#
Get_Data Get ( WindowRepCap window, LimitIxRepCap limitIx )
// SCPI: CALCulate<n>:LIMit<li>:ACPower:ACHannel:RESult
Get_Data value = driver.Applications.K91_Wlan.Calculate.Limit.AcPower.Achannel.Result.Get();
Get_Data value = driver.Applications.K91_Wlan.Calculate.Limit.AcPower.Achannel.Result.Get(WindowRepCap.Default, LimitIxRepCap.Default);

Queries the state of the limit check for the adjacent or alternate channels in an ACLR measurement. To get a valid result, you have to perform a complete measurement with synchronization to the end of the measurement before reading out the result. This is only possible for single measurement mode. See also method RsFsw.Applications.K10Xlte.Initiate.Continuous.Set.

For return value see the help for Get_Data structure arguments

window Repeated capability selector

limitIx Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

Direct SCPI Members

List<double>Get ( TraceNumberEnum traceType )#
List<double>Get ( TraceNumberEnum traceType, WindowRepCap window )
// SCPI: TRACe<n>[:DATA]:X
List<double> value = driver.Trace.Data.X.Get(TraceNumberEnum.BTOBits);
List<double> value = driver.Trace.Data.X.Get(TraceNumberEnum.BTOBits, WindowRepCap.Default);

This command queries the horizontal trace data for each sweep point in the specified window, for example the frequency in frequency domain or the time in time domain measurements. This is especially useful for traces with non-equidistant x-values.

traceType Trace number.

  • TRACE1 | … | TRACE6: TRACE1 | … | TRACE6

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

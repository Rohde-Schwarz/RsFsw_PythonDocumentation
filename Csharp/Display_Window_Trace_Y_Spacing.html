Switches the scaling mode for the deviation trace in the “Modulation Spectrum” between linear and logarithmic. Note: this setting only has an effect on the graphical results, not on the numerical results.

spacing LINear | LOGarithmic

  • LINear: Scaling in percent

  • LOGarithmic: Scaling in dB

window Repeated capability selector

trace Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

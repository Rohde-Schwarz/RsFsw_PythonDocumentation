Applications:K60Transient:Calculate:ChrDetection:Table:Results#

SCPI Commands

CALCulate<n>:CHRDetection:TABLe:RESults

Direct SCPI Members

class Get_Data

Response structure.

string Id

Timestamp which corresponds to the absolute time the beginning of the chirp was detected

double ChirpNo

Consecutive number of detected chirp, starts at 1 for each new measurement

double StateIndex

Consecutive number of corresponding nominal chirp state as defined in the Chirp States table (see method RsFsw.Applications.K60Transient.Calculate.ChrDetection.States.Data.Set())

string Begin

Time offset from the analysis region start at which the signal first enters the tolerance area of a nominal chirp

string Length

The duration of a chirp from begin to end, that is, the time the signal remains in the tolerance area of a nominal chirp.

string Crate

Derivative of the FM vs time trace within the frequency measurement range

double CrateDev

Deviation of the detected chirp rate from the nominal chirp state (in kHz/us) . For details see &quot;Chirp State Deviation&quot;.

double FreqAvg

Average frequency measured within the frequency measurement range of the chirp

double FmDevMax

Maximum deviation of the chirp frequency from the nominal chirp frequency as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see &quot;Frequency Deviation (Peak) &quot;.

double FmDevRms

RMS deviation of the chirp frequency from the nominal (linear) chirp frequency as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see &quot;Frequency Deviation (RMS) &quot;.

double FmDevAvg

Average deviation of the chirp frequency from the nominal (linear) chirp frequency as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see &quot;Frequency Deviation (Average) &quot;.

double PmDevMax

Maximum deviation of the chirp phase from the nominal chirp phase as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see &quot;Phase Deviation (Peak) &quot;.

double PmDevRms

RMS deviation of the chirp phase from the nominal (linear) chirp phase as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see &quot;Phase Deviation (RMS) &quot;.

double PmDevAvg

Average deviation of the chirp phase from the nominal (linear) chirp phase as defined in the Chirp States table. The deviation is calculated within the frequency measurement range of the chirp. For details see &quot;Phase Deviation (Average) &quot;.

double PowMin

Minimum power level measured during a chirp. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

double PowMax

Maximum power level measured during a chirp. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

double PowAvg

Average power level measured during a chirp. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

double PowRip

Power level measured during the chirp ripple time. Which part of the chirp precisely is used for calculation depends on the power parameters in the Power measurement range configuration.

Queries the chirp results table. The result is a comma-separated list of value sets, one set for each chirp. If no query parameters are specified, the results for all detected chirps are returned. Which values are returned depends on the enabled parameters for the results tables (see method RsFsw.Applications.K60Transient.Calculate.ChrDetection.Table.Column.Set) .

For return value see the help for Get_Data structure arguments

start The chirp number of the first chirp to be returned. Chirp numbers start at 1.

end The chirp number of the last chirp to be returned.

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

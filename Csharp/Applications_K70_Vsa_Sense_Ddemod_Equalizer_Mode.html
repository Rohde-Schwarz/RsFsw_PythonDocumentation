Switches between the equalizer modes. For details see “The equalizer”.

  • NORMal: Switches the equalizer on for the next sweep.

  • TRACking: Switches the equalizer on; the results of the equalizer in the previous sweep are considered to calculate the new filter.

  • FREeze: The filter is no longer changed, the current equalizer values are used for subsequent sweeps.

  • USER: A user-defined equalizer loaded from a file is used.

  • AVERaging: Switches the equalizer on; the results of the equalizer in all previous sweeps (since the instrument was switched on or the equalizer was reset) are considered to calculate the new filter. To start a new averaging process, use the [SENSe:]DDEMod:EQUalizer:RESet command.

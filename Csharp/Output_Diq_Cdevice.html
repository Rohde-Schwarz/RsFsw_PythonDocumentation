OUTPut:DIQ:CDEVice

Direct SCPI Members

class Get_Data

Response structure.

double ConnState

Defines whether a device is connected or not.

  • 0: No device is connected.

  • 1: A device is connected.

double DeviceName

Device ID of the connected device

double SerialNumber

Serial number of the connected device

double PortName

Port name used by the connected device

double SampleRate

Current data transfer rate of the connected device in Hz

double MaxTransferRate

Maximum data transfer rate of the connected device in Hz

double ConnProtState

State of the connection protocol which is used to identify the connected device.

  • Not Started:

  • Has to be Started: Has to be Started

  • Started: Started

  • Passed: Passed

  • Failed: Failed

  • Done: Done

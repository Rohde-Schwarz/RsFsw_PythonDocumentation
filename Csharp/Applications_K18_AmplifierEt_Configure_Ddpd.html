Direct SCPI Members

void Continue ( )#
void ContinueAndWait ( )#
void ContinueAndWait ( int opcTimeoutMs )
// SCPI: CONFigure:DDPD:CONTinue
driver.Applications.K18_AmplifierEt.Configure.Ddpd.Continue();
driver.Applications.K18_AmplifierEt.Configure.Ddpd.ContinueAndWait();
driver.Applications.K18_AmplifierEt.Configure.Ddpd.ContinueAndWait(1000);

Continues direct DPD in manual mode.

ContinueAndWait is the same as Continue, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

void Abort ( )#
void AbortAndWait ( )#
void AbortAndWait ( int opcTimeoutMs )
// SCPI: CONFigure:DDPD:ABORt
driver.Applications.K18_AmplifierEt.Configure.Ddpd.Abort();
driver.Applications.K18_AmplifierEt.Configure.Ddpd.AbortAndWait();
driver.Applications.K18_AmplifierEt.Configure.Ddpd.AbortAndWait(1000);

This command stops a DPD sequence and discards the predistorted I/Q data that have been calculated. Prerequisites for this command

  • Turn on direct DPD (method RsFsw.Applications.K18AmplifierEt.Configure.Ddpd.State.Set) .

  • Initiate a DPD sequence (method RsFsw.Applications.K18AmplifierEt.Configure.Ddpd.Start) .

AbortAndWait is the same as Abort, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

This command initiates a direct DPD sequence with the number of iterations you have defined. You can define the number of iterations with CONFigure:DDPD:COUNt. Prerequisites for this command

  • Turn on direct DPD (method RsFsw.Applications.K18AmplifierEt.Configure.Ddpd.State.Set) .

StartAndWait is the same as Start, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

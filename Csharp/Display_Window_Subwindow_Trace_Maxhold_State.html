Switches the maxhold trace in the persistence spectrum on and off. Note: Setting the intensity to 0 has the same effect as deactivating the Maxhold function (see method RsFsw.Display.Window.Subwindow.Trace.Maxhold.Intensity.Set) .

state ON | OFF | 0 | 1

  • OFF | 0: Switches the function off

  • ON | 1: Switches the function on

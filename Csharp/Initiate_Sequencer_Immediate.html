Initiate:Sequencer:Immediate#

SCPI Commands

INITiate:SEQuencer:IMMediate

Direct SCPI Members

void Perform ( )#
void PerformAndWait ( )#
void PerformAndWait ( int opcTimeoutMs )
// SCPI: INITiate:SEQuencer:IMMediate
driver.Initiate.Sequencer.Immediate.Perform();
driver.Initiate.Sequencer.Immediate.PerformAndWait();
driver.Initiate.Sequencer.Immediate.PerformAndWait(1000);

Starts a new sequence of measurements by the Sequencer. Its effect is similar to the method RsFsw.Applications.K10Xlte.Initiate.Immediate.Perform command used for a single measurement. Before this command can be executed, the Sequencer must be activated (see method RsFsw.System.Sequencer.Set) .

PerformAndWait is the same as Perform, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

This command defines the origin of the x-axis in the time domain result display. Prerequisites for this command

  • Turn off automatic scaling (DISPlay[:WINDow<n>]:TDOMain:X[:SCALe]:MODE) .

time Time offset relative to the first recorded sample (when synchronization has failed) or the first sample of the synchronized data (when synchronization was successful) .

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

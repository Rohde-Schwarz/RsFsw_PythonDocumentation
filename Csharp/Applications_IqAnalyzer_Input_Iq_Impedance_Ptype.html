Defines the type of matching pad used for impedance conversion for analog baseband input. For RF input, use the method RsFsw.Input.Impedance.Ptype.Set command.

padType SRESistor | MLPad

  • SRESistor: Series-R

  • MLPad: Minimum Loss Pad

input Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

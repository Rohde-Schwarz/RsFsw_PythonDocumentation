Exports trace data from the specified window to an ASCII file. Secure User Mode In secure user mode, settings that are stored on the instrument are stored to volatile memory, which is restricted to 256 MB. Thus, a memory limit reached error can occur although the hard disk indicates that storage space is still available. To store data permanently, select an external storage location such as a USB memory device. For details, see .

trace Number of the trace to be stored

filename String containing the path and name of the target file.

store Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

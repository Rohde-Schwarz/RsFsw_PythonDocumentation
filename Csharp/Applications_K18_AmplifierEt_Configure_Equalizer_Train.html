This command initiates a training sequence for the equalizer filter. Note that you have to synchronize the measurement before you can initiate a training sequence. Prerequisites for this command

  • Define a filter length (CONFigure:EQUalizer:FILTer:LENGth) .

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

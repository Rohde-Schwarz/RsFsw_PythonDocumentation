void Save ( string filename )#
// SCPI: [SENSe]:LIST:SAVE
driver.Applications.K50_Spurious.Sense.List.Save("abc");

Saves the current range setup to a user-defined comma-separated (.csv) file for later use. The values are stored in the following order for each range: <No>,<Start>,<Stop>,<TNRStart>,<TNRStop>,<LimitOffset>,<PeakExcursion>,<SNR>,<AutoRBW>,<RBW>,<MaxFinalRBW>,<Detector>,<DetLength>,<Reserved>,<RefLevel>,<RFAttenuation>,<Preamp>

filename String containing the path and name of the file.

void Load ( string filename )#
// SCPI: [SENSe]:LIST:LOAD
driver.Applications.K50_Spurious.Sense.List.Load("abc");

Loads a stored range setup from a .csv file. The current settings in the table are overwritten by the settings in the file!

void Clear ( )#
void ClearAndWait ( )#
void ClearAndWait ( int opcTimeoutMs )
// SCPI: [SENSe]:LIST:CLEar
driver.Applications.K50_Spurious.Sense.List.Clear();
driver.Applications.K50_Spurious.Sense.List.ClearAndWait();
driver.Applications.K50_Spurious.Sense.List.ClearAndWait(1000);

Removes all but the first range from the wide search settings table.

ClearAndWait is the same as Clear, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

Defines the distance of the n dB down markers to the reference marker.

distance Distance of the temporary markers to the reference marker in dB. For a positive offset, the markers T1 and T2 are placed below the active reference point. For a negative offset (for example for notch filter measurements) , the markers T1 and T2 are placed above the active reference point.

window Repeated capability selector

marker Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

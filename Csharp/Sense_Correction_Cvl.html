Direct SCPI Members

void Clear ( )#
void ClearAndWait ( )#
void ClearAndWait ( int opcTimeoutMs )
// SCPI: [SENSe]:CORRection:CVL:CLEar
driver.Sense.Correction.Cvl.Clear();
driver.Sense.Correction.Cvl.ClearAndWait();
driver.Sense.Correction.Cvl.ClearAndWait(1000);

Deletes the selected conversion loss table. Before this command can be performed, the conversion loss table must be selected (see method RsFsw.Applications.K50Spurious.Sense.Correction.Cvl.Select.Set) . Is only available with option B21 (External Mixer) installed.

ClearAndWait is the same as Clear, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

Direct SCPI Members

void Copy ( string pattern )#
// SCPI: [SENSe]:DDEMod:SEARch:SYNC:COPY
driver.Applications.K70_Vsa.Sense.Ddemod.Search.Sync.Copy("abc");

Copies a pattern file. The pattern to be copied must have been selected before using method RsFsw.Applications.K70Vsa.Sense.Ddemod.Search.Sync.Name.Set. Tip: In manual operation, a pattern can be copied in the editor by storing it under a new name.

void Delete ( )#
void DeleteAndWait ( )#
void DeleteAndWait ( int opcTimeoutMs )
// SCPI: [SENSe]:DDEMod:SEARch:SYNC:DELete
driver.Applications.K70_Vsa.Sense.Ddemod.Search.Sync.Delete();
driver.Applications.K70_Vsa.Sense.Ddemod.Search.Sync.DeleteAndWait();
driver.Applications.K70_Vsa.Sense.Ddemod.Search.Sync.DeleteAndWait(1000);

Deletes a sync sequence. The sync sequence to be deleted must have been selected before using method RsFsw.Applications.K70Vsa.Sense.Ddemod.Search.Sync.Name.Set.

DeleteAndWait is the same as Delete, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

Switches the RBW between Auto and Manual. The Auto mode automatically selects an optimal RBW.

bandwidthResolutionAuto AUTO | MANual

  • AUTO: Selects automatically an optimal RBW.

  • MANual: Enables manual input for the RBW.

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

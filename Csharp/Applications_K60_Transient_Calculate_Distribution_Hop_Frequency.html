Configures the Parameter Distribution result display for hop frequency parameters.

xaxis AVGFm | FMERror | FREQuency | MAXFm | RELFrequency | RMSFm

  • FREQuency: Average frequency

  • RELFrequency: Relative frequency (hop-to-hop)

  • FMERror: Hop state deviation

  • MAXFm: Maximum Frequency Deviation

  • RMSFm: RMS Frequency Deviation

  • AVGFm: Average Frequency Deviation

yaxis Parameter to be displayed on the y-axis.

  • COUNt: Number of hops in which the parameter value occurred.

  • OCCurance: Percentage of all measured hops in which the parameter value occurred.

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

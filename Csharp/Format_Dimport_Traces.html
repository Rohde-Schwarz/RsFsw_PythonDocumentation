Format:Dimport:Traces#

SCPI Commands

FORMat:DIMPort:TRACes

Direct SCPI Members

SelectionScopeEnum Get ( )#
void Set ( SelectionScopeEnum selection )#
// SCPI: FORMat:DIMPort:TRACes
// Get:
SelectionScopeEnum value = driver.Format.Dimport.Traces.Get();
// Set:
driver.Format.Dimport.Traces.Set(SelectionScopeEnum.ALL);

Selects the data to be included in a data import file (see method RsFsw.MassMemory.Load.Trace.Set) .

selection SINGle | ALL

  • SINGle: Only a single trace is selected for import, namely the one specified by the MMEMory:LOADn:TRACe command.

  • ALL: Imports several traces at once, overwriting the existing trace data for any active trace in the result display with the same trace number. Data from the import file for currently not active traces is not imported.The trace parameter for the MMEMory:LOADn:TRACe command is ignored.

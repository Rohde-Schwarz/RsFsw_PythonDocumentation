This command defines the amount of data displayed on the x-axis of the time domain result display. Prerequisites for this command

  • Turn off automatic scaling (DISPlay[:WINDow<n>]:TDOMain:X[:SCALe]:MODE) .

time Time that is displayed on the x-axis, beginning at the offset defined with method RsFsw.Applications.K18AmplifierEt.Display.Window.Tdomain.X.Scale.Offset.Set().

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

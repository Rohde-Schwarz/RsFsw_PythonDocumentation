class Enable_Data

Structure for setting input parameters. Contains optional set arguments.

int BitDefinition

0 to Max Uint16

string AppName

Optional settings argument. String containing the name of the channel. The parameter is optional. If you omit it, the command works for the currently active channel.

Controls the ENABle part of a register. The ENABle part allows true conditions in the EVENt part of the status register to be reported in the summary bit. If a bit is 1 in the enable register and its associated event bit transitions to true, a positive transition will occur in the summary bit reported to the next higher level.

settings For set / get value, see the help for Enable_Data structure arguments

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

Applications:K70Vsa:Calculate:Marker:Y#

SCPI Commands

CALCulate<n>:MARKer<m>:Y

Direct SCPI Members

// SCPI: CALCulate<n>:MARKer<m>:Y
double value = driver.Applications.K70_Vsa.Calculate.Marker.Y.Get();
double value = driver.Applications.K70_Vsa.Calculate.Marker.Y.Get(WindowRepCap.Default, MarkerRepCap.Default);

Queries the position of a marker on the y-axis. In result displays with a third aspect (for example EVM vs Symbol x Carrier) , you can also use the command to define the position of the marker on the y-axis. If necessary, the command activates the marker first. To get a valid result, you have to perform a complete measurement with synchronization to the end of the measurement before reading out the result. This is only possible for single measurement mode. See also method RsFsw.Applications.K10Xlte.Initiate.Continuous.Set.

result: Result at the marker position. The type of value and its unit depend on the selected result display.

window Repeated capability selector

marker Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

driver.Initiate.Sequencer.Refresh.All.Set();
driver.Initiate.Sequencer.Refresh.All.SetAndWait();
driver.Initiate.Sequencer.Refresh.All.SetAndWait(1000);

Is only available if the Sequencer is deactivated (SYST:SEQ:OFF) and only in MSRT mode. The data in the capture buffer is re-evaluated by all active MSRT secondary applications.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

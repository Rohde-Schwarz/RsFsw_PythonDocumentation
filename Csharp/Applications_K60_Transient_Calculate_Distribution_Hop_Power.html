driver.Applications.K60_Transient.Calculate.Distribution.Hop.Power.Set(AxisPowerEnum.AVGPower, YaXisItemsEnum.COUNt);

Configures the Parameter Distribution result display for hop power parameters.

xaxis AVGPower | MAXPower | MINPower | PWRRipple

  • MINPower: Minimum power

  • MAXPower: Maximum power

  • AVGPower: Average power

  • PWRRipple: Power ripple

yaxis Parameter to be displayed on the y-axis.

  • COUNt: Number of hops in which the parameter value occurred.

  • OCCurance: Percentage of all measured hops in which the parameter value occurred.

window Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

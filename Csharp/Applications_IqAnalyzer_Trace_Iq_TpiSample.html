Applications:IqAnalyzer:Trace:Iq:TpiSample#

SCPI Commands

TRACe:IQ:TPISample

Direct SCPI Members

double Get ( )#
// SCPI: TRACe:IQ:TPISample
double value = driver.Applications.IqAnalyzer.Trace.Iq.TpiSample.Get();

Queries the time offset from the sample start to the trigger event (trigger point in sample = TPIS) . Since the FSW usually samples with a much higher sample rate than the specific application actually requires, the trigger point determined internally is much more precise than the one determined from the (downsampled) data in the application. Thus, the TPIS indicates the offset from the sample start to the actual trigger event. This value can only be determined in triggered measurements using external or IFPower triggers, otherwise the value is 0. Is not available if the Digital Baseband interface (FSW-B17) is active.

tpis: numeric value

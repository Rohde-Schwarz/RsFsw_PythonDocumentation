double value = driver.Applications.K70_Vsa.Calculate.Marker.Function.Ddemod.Statistic.Gimbalance.Get(ResultTypeStatEnum.AVG, WindowRepCap.Default, MarkerRepCap.Default);

Queries the results of the Gain Imbalance error measurement of digital demodulation. The output values are the same as those provided in the Modulation Accuracy table .

  • none: Gain imbalance error for current sweep

  • AVG: Average gain imbalance error over several sweeps

  • RPE: Peak gain imbalance error over several sweeps

  • SDEV: Standard deviation of gain imbalance error

  • PCTL: 95 percentile value of gain imbalance error

window Repeated capability selector

marker Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

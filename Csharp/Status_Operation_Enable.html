Status:Operation:Enable#

SCPI Commands

STATus:OPERation:ENABle

Direct SCPI Members

int Get ( )#
void Set ( int summaryBit )#
// SCPI: STATus:OPERation:ENABle
// Get:
int value = driver.Status.Operation.Enable.Get();
// Set:
driver.Status.Operation.Enable.Set(1);

Controls the ENABle part of a register. The ENABle part allows true conditions in the EVENt part of the status register to be reported in the summary bit. If a bit is 1 in the enable register and its associated event bit transitions to true, a positive transition will occur in the summary bit reported to the next higher level. Note: if you switch between the IQ measurement and MCWN measurement, the transition is set to its default value. Thus, you must reconfigure the transition after switching measurements, if necessary.

// Set:
driver.Applications.K18_AmplifierEt.Configure.Modeling.Scale.Set(ScalingModeEnum.LINear);

This command selects the method by which the input power range is split into smaller ranges for the calculation of the amplifier model.

  • LINear: Input power range is split on a linear basis.

  • LOGarithmic: Input power range is split on a logarithmic basis.

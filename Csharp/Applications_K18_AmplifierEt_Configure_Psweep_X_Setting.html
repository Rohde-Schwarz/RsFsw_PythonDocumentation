// SCPI: CONFigure:PSWeep:X:SETTing
// Get:
PsweepSettingEnum value = driver.Applications.K18_AmplifierEt.Configure.Psweep.X.Setting.Get();
// Set:
driver.Applications.K18_AmplifierEt.Configure.Psweep.X.Setting.Set(PsweepSettingEnum.BIAS);

This command selects the parameter type for the first parameter controlled by the parameter sweep.

  • BIAS: Controls the envelope bias.

  • DELay: Controls the delay between envelope and RF signal.

  • FREQuency: Controls the frequency.

  • POWer: Controls the output level.

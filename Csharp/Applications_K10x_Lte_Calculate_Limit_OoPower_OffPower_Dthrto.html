Defines the limit for the spectral density in the frequency range 3 GHz to 4.2 GHz. For other frequencies, define the limits with CALCulate<n>:LIMit:OOPower:OFFPower:DENSity.

  • numeric_value: Limit in dBm/Hz.

  • DEFault: Restores the default limits as defined by 3GPP.

window Repeated capability selector

limitIx Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

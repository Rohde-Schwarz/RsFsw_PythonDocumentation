Defines the file name of the conversion loss table to be used for the low (first) range.

tableLow String containing the path and name of the file, or the serial number of the external mixer whose file is required. The FSW automatically selects the correct cvl file for the current IF. As an alternative, you can also select a user-defined conversion loss table (.acl file) .

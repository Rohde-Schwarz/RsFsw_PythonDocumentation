driver.Applications.K40_PhaseNoise.Sense.Sweep.FhDecade.Set();
driver.Applications.K40_PhaseNoise.Sense.Sweep.FhDecade.SetAndWait();
driver.Applications.K40_PhaseNoise.Sense.Sweep.FhDecade.SetAndWait(1000);

Stops the measurement in the current half decade and continues measuring in the subsequent half decade.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

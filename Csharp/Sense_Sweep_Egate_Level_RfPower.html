Sense:Sweep:Egate:Level:RfPower#

Defines the gate level for which the gate is open. Note that any RF attenuation or preamplification is considered when the trigger level is analyzed. If defined, a reference level offset is also considered. The input signal must be between 500 MHz and 8 GHz. Is only available for triggered gated measurements (method RsFsw.Sense.Sweep.Egate.Auto.SetMAN) .

gateLevel For details on available trigger levels and trigger bandwidths, refer to the specifications document.

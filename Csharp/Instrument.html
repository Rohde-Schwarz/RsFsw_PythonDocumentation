void Abort ( )#

void AbortAndWait ( int opcTimeoutMs )
// SCPI: INSTrument:ABORt
driver.Instrument.Abort();
driver.Instrument.AbortAndWait();
driver.Instrument.AbortAndWait(1000);

No help available.

AbortAndWait is the same as Abort, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

void Delete ( string appName )#
// SCPI: INSTrument:DELete
driver.Instrument.Delete("rawAbc");

Deletes a channel. If you delete the last channel, the default Spectrum channel is activated.

appName String containing the name of the channel you want to delete. A channel must exist to delete it.

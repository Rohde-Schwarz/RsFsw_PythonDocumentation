Specifies the start offset of the FFT for OFDM demodulation (not for the FFT Spectrum display) .

mode AUTO | GICenter | PEAK

  • AUTO: The FFT start offset is automatically chosen to minimize the intersymbol interference.

  • GICenter: Guard Interval Center: The FFT start offset is placed to the center of the guard interval.

  • PEAK: The peak of the fine timing metric is used to determine the FFT start offset.

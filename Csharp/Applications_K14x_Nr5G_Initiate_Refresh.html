The data in the capture buffer is re-evaluated by the R&S FSW DOCSIS 3.1 application. This is useful, for example, after evaluation changes have been made. This function is only available if the Sequencer is deactivated and only in single sweep mode.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsFsw.Utilities.OpcTimeout.

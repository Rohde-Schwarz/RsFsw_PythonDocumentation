string Get ( SelectionRangeEnum queryRange )#

string value = driver.Applications.K6_Pulse.Sense.Pulse.Phase.Deviation.Get(SelectionRangeEnum.ALL);

Returns the phase deviation for the specified pulse(s) .

result: char_data

queryRange SELected | CURRent | ALL

  • SELected: Currently selected pulse

  • CURRent: Detected pulses in the current capture buffer

  • ALL: All detected pulses in the entire measurement.

Defines the total attenuation for RF input. If an electronic attenuator is available and active, the command defines a mechanical attenuation (see method RsFsw.Applications.K17Mcgd.Input.Eatt.State.Set) . If you set the attenuation manually, it is no longer coupled to the reference level, but the reference level is coupled to the attenuation. Thus, if the current reference level is not compatible with an attenuation that has been set manually, the command also adjusts the reference level. If an external frontend is active (see [SENSe:]EFRontend[:STATe]) , you can configure the attenuation of the external frontend and the analyzer separately. See also method RsFsw.Input.Sanalyzer.Attenuation.Auto.Set and method RsFsw.Input.Sanalyzer.Attenuation.Set. Is not available if the optional Digital Baseband interface is active.

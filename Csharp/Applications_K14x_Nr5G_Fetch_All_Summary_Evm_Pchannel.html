Applications:K14Xnr5G:Fetch:All:Summary:Evm:Pchannel#

SCPI Commands

FETCh:ALL:SUMMary:EVM:PCHannel

Direct SCPI Members

double Get ( )#
// SCPI: FETCh:ALL:SUMMary:EVM:PCHannel
double value = driver.Applications.K14x_Nr5G.Fetch.All.Summary.Evm.Pchannel.Get();

Queries the EVM of the physical channel. method RsFsw.Applications.K14Xnr5G.Fetch.All.Summary.Evm.Pchannel.Get queries the average result over all carriers. Prerequisites:

  • Select to evaluate all carriers ([SENSe:]NR5G:RSUMmary:CCResult) .

result: Available for combined measurements. Queries the EVM of all events (meas IDs) . Omitting this parameter queries the EVM of the selected event.

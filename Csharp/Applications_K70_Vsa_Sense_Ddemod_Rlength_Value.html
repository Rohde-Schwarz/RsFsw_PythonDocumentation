Defines or queries the capture length for further processing, e.g. for burst search. Note that the maximum capture length depends on the sample rate for signal capture (see method RsFsw.Applications.K70Vsa.Sense.Ddemod.Prate.Set) .

recordLength The capture length can be defined in time (seconds) or symbols (SYM) . The return value is always in time (s) . To query the capture length in symbols, use the method RsFsw.Applications.K70Vsa.Sense.Ddemod.Rlength.Symbols.Value.Set() command.

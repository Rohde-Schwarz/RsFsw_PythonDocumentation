# [SENSe]:CHIRp:FREQuency:MAXNonlinear:MINimum
value: float = driver.applications.k60Transient.sense.chirp.frequency.maxNonlinear.minimum.get(query_range = enums.SelectionRangeB.ALL)

Returns the statistical value for the maximum frequency integrated non-linearity from the statistics table for the specified chirp(s) .

Parameters:

query_range – CURRent | ALL

  • CURRent: Detected chirps in the current capture buffer

  • ALL: All chirps detected in the entire measurement

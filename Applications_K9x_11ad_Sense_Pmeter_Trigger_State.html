# [SENSe]:PMETer<p>:TRIGger[:STATe]
# get:
value: bool = driver.applications.k9X11Ad.sense.pmeter.trigger.state.get(powerMeter = repcap.PowerMeter.Default)
# set:
driver.applications.k9X11Ad.sense.pmeter.trigger.state.set(arg_0 = False, powerMeter = repcap.PowerMeter.Default)

Turns the external power trigger on and off. Requires the use of a Rohde & Schwarz power sensor. For a list of supported sensors, see the specifications document.

Parameters:

  • arg_0 – ON | OFF | 0 | 1

    • OFF | 0: Switches the function off

    • ON | 1: Switches the function on

  • powerMeter – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Pmeter’)

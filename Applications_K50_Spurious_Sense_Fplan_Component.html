# [SENSe]:FPLan:COMPonent<co>:DELete
driver.applications.k50Spurious.sense.fplan.component.delete(component = repcap.Component.Default)
driver.applications.k50Spurious.sense.fplan.component.delete_with_opc(component = repcap.Component.Default, opc_timeout_ms = 3000)

Will delete the selected row from the frequency plan.

delete_with_opc() does the same as delete(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

  • component – optional repeated capability selector. Default value: Ix1 (settable in the interface ‘Component’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

Selects the antenna port(s) on which the CSI reference signal is transmitted.

Parameters:

  • state –

    • ON | OFF | 1 | 0: Turns a specific CSI-RS antenna port on and off.

    • ALL | NONE: Turns all CSI-RS antenna port on and off.

  • carrierComponent – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Cc’)

  • antennaPortConfig – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Pamapping’)

  • antennaPort3k – optional repeated capability selector. Default value: Nr3000 (settable in the interface ‘Ap’)

delete_with_opc() does the same as delete(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

  • rangePy – optional repeated capability selector. Default value: Ix1 (settable in the interface ‘Range’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

Auto#

SCPI Command :

MMEMory:LOAD:IQ:STReam:AUTO
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( ) → bool
set ( state: bool ) → None
# MMEMory:LOAD:IQ:STReam:AUTO
# get:
value: bool = driver.applications.k10Xlte.massMemory.load.iq.stream.auto.get()
# set:
driver.applications.k10Xlte.massMemory.load.iq.stream.auto.set(state = False)

Only available for files that contain more than one data stream from multiple channels: automatically defines which data stream in the file is used as input for the channel.

Parameters:

state – ON | OFF | 0 | 1

  • OFF | 0: The data stream specified by MMEMory:LOAD:IQ:STReam is used as input for the channel.

  • ON | 1: The first data stream in the file is used as input for the channel. Applications that support multiple data streams use the first data stream in the file for the first input stream, the second for the second stream etc.

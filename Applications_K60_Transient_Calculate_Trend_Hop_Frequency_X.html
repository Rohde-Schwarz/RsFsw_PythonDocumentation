# CALCulate<n>:TRENd:HOP:FREQuency:X
driver.applications.k60Transient.calculate.trend.hop.frequency.x.set(xaxis = enums.AxisFreqFmItems.AVGFm, window = repcap.Window.Default)

Configures the x-axis of the Parameter Trend result display for hop frequency parameters.

Parameters:

  • xaxis – AVGFm | FMERror | FREQuency | MAXFm | RELFrequency | RMSFm

    • FREQuency: Average frequency

    • RELFrequency: Relative frequency (hop-to-hop)

    • FMERror: Hop state deviation

    • MAXFm: Maximum Frequency Deviation

    • RMSFm: RMS Frequency Deviation

    • AVGFm: Average Frequency Deviation

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

Turns an event filter on and off. Turning on an event filter adds it to the filter list and removes the results from the result summary that do not fulfill the filter conditions. Turning it off removes it from the list. Prerequisites for this command

  • Define a filter condition ([SENSe:]NR5G:EFILter:FPARameters) .

Parameters:

  • result – Selects the result that you want to add a filter for.

  • state – ON | OFF | 1 | 0

Returns:

# CONFigure:DDPD:ABORt
driver.applications.k18AmplifierEt.configure.ddpd.abort()
driver.applications.k18AmplifierEt.configure.ddpd.abort_with_opc(opc_timeout_ms = 3000)

This command stops a DPD sequence and discards the predistorted I/Q data that have been calculated. Prerequisites for this command

  • Turn on direct DPD (method RsFsw.applications.k18AmplifierEt.configure.ddpd.state.set() ) .

  • Initiate a DPD sequence (method RsFsw.applications.k18AmplifierEt.configure.ddpd.start() ) .

abort_with_opc() does the same as abort(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

driver.applications.k18AmplifierEt.configure.ddpd.start_with_opc(opc_timeout_ms = 3000)

This command initiates a direct DPD sequence with the number of iterations you have defined. You can define the number of iterations with CONFigure:DDPD:COUNt. Prerequisites for this command

  • Turn on direct DPD (method RsFsw.applications.k18AmplifierEt.configure.ddpd.state.set() ) .

start_with_opc() does the same as start(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

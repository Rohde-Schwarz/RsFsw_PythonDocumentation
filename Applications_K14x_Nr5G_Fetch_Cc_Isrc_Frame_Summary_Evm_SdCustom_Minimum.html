# FETCh[:CC<cc>][:ISRC][:FRAMe<fr>]:SUMMary:EVM:SDCustom:MINimum
value: float = driver.applications.k14Xnr5G.fetch.cc.isrc.frame.summary.evm.sdCustom.minimum.get(result = enums.SelectAll.ALL, carrierComponent = repcap.CarrierComponent.Default, frame = repcap.Frame.Default)

Queries the EVM of all PUSCH DMRS resource elements with a custom modulation. Prerequisites for this command

  • Use custom constellation (CONFigure[:NR5G]:UL[:CC<cc>]:FRAMe<fr>:BWPart<bwp>:SLOT<sl>:ALLocation<al>:CUSTom:STATe) .

method RsFsw.applications.k14Xnr5G.fetch.all.summary.evm.ds1K.get() queries the average result over all carriers. Prerequisites:

  • Select to evaluate all carriers ([SENSe:]NR5G:RSUMmary:CCResult) .

Parameters:

  • result – Available for combined measurements. Queries the EVM of all events (meas IDs) . Omitting this parameter queries the EVM of the selected event.

  • carrierComponent – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Cc’)

  • frame – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Frame’)

Returns:

evm: EVM in % or dB.

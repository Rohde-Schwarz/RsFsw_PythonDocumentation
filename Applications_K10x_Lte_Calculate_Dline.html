# set:
driver.applications.k10Xlte.calculate.dline.set(position = 1.0, window = repcap.Window.Default, displayLine = repcap.DisplayLine.Default)

Defines the (horizontal) position of a display line.

Parameters:

  • position – The value range is variable. You can use any unit you want, the FSW then converts the unit to the currently selected unit. If you omit a unit, the FSW uses the currently selected unit.

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

  • displayLine – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Dline’)

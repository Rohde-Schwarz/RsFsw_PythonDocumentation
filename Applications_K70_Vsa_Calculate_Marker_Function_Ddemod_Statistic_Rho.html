# CALCulate<n>:MARKer<m>:FUNCtion:DDEMod:STATistic:RHO
value: float = driver.applications.k70Vsa.calculate.marker.function.ddemod.statistic.rho.get(result_type = enums.ResultTypeStat.AVG, window = repcap.Window.Default, marker = repcap.Marker.Default)

Queries the results of the Rho factor measurement performed for digital demodulation.

Parameters:

  • result_type –

    • none: Rho factor (for current sweep)

    • AVG: Average rho factor over several sweeps

    • RPE: Peak rho factor over several sweeps

    • SDEV: Standard deviation of rho factor

    • PCTL: 95 percentile value of rho factor

  • window – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Calculate’)

  • marker – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Marker’)

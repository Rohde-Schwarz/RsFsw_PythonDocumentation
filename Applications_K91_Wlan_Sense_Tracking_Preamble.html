Preamble#

SCPI Command :

[SENSe]:TRACking:PREamble
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( ) → bool
set ( mode: bool ) → None
# [SENSe]:TRACking:PREamble
# get:
value: bool = driver.applications.k91Wlan.sense.tracking.preamble.get()
# set:
driver.applications.k91Wlan.sense.tracking.preamble.set(mode = False)

Defines which results are used for preamble tracking prior to the preamble channel estimation.

Parameters:

mode –

  • OFF | PAYLoad: Payload tracking results are used for preamble tracking prior to the preamble channel estimation

  • ON | VHT: (V) HT-LTF Symbols and Payload tracking results are used for preamble tracking prior to the preamble channel estimation.

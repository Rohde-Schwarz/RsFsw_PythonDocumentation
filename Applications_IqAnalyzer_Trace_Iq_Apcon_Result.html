# TRACe:IQ:APCon:RESult
value: float = driver.applications.iqAnalyzer.trace.iq.apcon.result.get()

Queries the average power consumption for an analog baseband input. This value is only calculated at the end of the I/Q data measurement if the method RsFsw.trace.iq.apcon.state.set() command is set to ON before the measurement is performed! For details see ‘Average power consumption’.

Returns:

avg_power: numeric value

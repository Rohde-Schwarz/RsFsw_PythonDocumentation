# [SENSe]:FREQuency:OFFSet
# get:
value: float = driver.applications.k14Xnr5G.sense.frequency.offset.get()
# set:
driver.applications.k14Xnr5G.sense.frequency.offset.set(offset = 1.0)

Defines a frequency offset. If this value is not 0 Hz, the application assumes that the input signal was frequency shifted outside the application. All results of type ‘frequency’ will be corrected for this shift numerically by the application. See also ‘Frequency Offset’. Note: In MSRA mode, the setting command is only available for the MSRA primary application. For MSRA secondary applications, only the query command is available.

Parameters:

offset – -1 THz to 1 THz

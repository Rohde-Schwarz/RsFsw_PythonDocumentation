Snumber#

SCPI Command :

[SENSe]:CORRection:CVL:SNUMber
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( serial_number: str ) → str
set ( serial_number: str ) → None
# [SENSe]:CORRection:CVL:SNUMber
# get:
value: str = driver.applications.k9X11Ad.sense.correction.cvl.snumber.get(serial_number = 'abc')
# set:
driver.applications.k9X11Ad.sense.correction.cvl.snumber.set(serial_number = 'abc')

Defines the serial number of the mixer for which the conversion loss table is to be used. This setting is checked against the current mixer setting before the table can be assigned to the range. Before this command can be performed, the conversion loss table must be selected (see method RsFsw.applications.k50Spurious.sense.correction.cvl.select.set() ) . Is only available with option B21 (External Mixer) installed.

Parameters:

serial_number – Serial number with a maximum of 16 characters

value: bool = driver.applications.k91Wlan.sense.demod.cestimation.get()
# set:
driver.applications.k91Wlan.sense.demod.cestimation.set(state = False)

Note that this command is maintained for compatibility reasons only. Use method RsFsw.applications.k91Wlan.sense.demod.cestimation.range.set() for new remote control programs. Defines whether channel estimation uses preamble and payload or only preamble. Channel estimation using both the preamble and the payload improves the EVM measurement results. However, this functionality is not supported by the IEEE 802.11 standard and must be disabled if the results are to be measured strictly according to the standard.

Parameters:

state – ON | OFF | 1 | 0

  • ON | 1: The channel estimation is performed using the preamble and the payload. The EVM results can be calculated more accurately.

  • OFF | 0: The channel estimation is performed using the preamble only as required in the standard.

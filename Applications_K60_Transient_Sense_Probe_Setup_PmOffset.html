PmOffset#

SCPI Command :

[SENSe]:PROBe<pb>:SETup:PMOFfset
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( probe=Probe.Default ) → float
set ( pm_offset: float, probe=Probe.Default ) → None
# [SENSe]:PROBe<pb>:SETup:PMOFfset
# get:
value: float = driver.applications.k60Transient.sense.probe.setup.pmOffset.get(probe = repcap.Probe.Default)
# set:
driver.applications.k60Transient.sense.probe.setup.pmOffset.set(pm_offset = 1.0, probe = repcap.Probe.Default)

Sets the P-mode offset. The setting is only available if a modular probe in P-mode is connected to the FSW. The maximum voltage difference between the positive and negative input terminals is 16 V. If the probe is disconnected, the P-mode offset of the probe is reset to 0.0 V. Note that if the offset for DM-mode or CM-mode is changed, the offsets for the P-mode and N-mode are adapted accordingly, and vice versa. For details see .

Parameters:

  • pm_offset – The voltage offset between the positive input terminal and ground.

  • probe – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Probe’)

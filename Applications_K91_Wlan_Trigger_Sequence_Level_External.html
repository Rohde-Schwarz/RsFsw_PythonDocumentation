driver.applications.k91Wlan.trigger.sequence.level.external.set(trigger_level = 1.0, externalPort = repcap.ExternalPort.Default)

Defines the level the external signal must exceed to cause a trigger event. Note that the variable Input/Output connectors (ports 2+3) must be set for use as input using the method RsFsw.applications.k17Mcgd.output.trigger.direction.set() command. For details on the trigger source see ‘Trigger Source’.

Parameters:

  • trigger_level – 0.5 V to 3.5 V

  • externalPort – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘External’)

# FETCh:ALL:SUMMary:EVM:PSIGnal
value: float = driver.applications.k14Xnr5G.fetch.all.summary.evm.psignal.get()

Queries the EVM of the physical signal. method RsFsw.applications.k14Xnr5G.fetch.all.summary.evm.psignal.get() queries the average result over all carriers. Prerequisites:

  • Select to evaluate all carriers ([SENSe:]NR5G:RSUMmary:CCResult) .

Returns:

result: Available for combined measurements. Queries the EVM of all events (meas IDs) . Omitting this parameter queries the EVM of the selected event.

Commands in total: 1

get ( ) → int

# CONFigure:EDMG:NCB
# get:
value: int = driver.applications.k9X11Ad.configure.edmg.ncb.get()
# set:
driver.applications.k9X11Ad.configure.edmg.ncb.set(ncb = 1)

Indicates the number of contiguous 2.16 GHz channels the measurement was made for. Note that the FSW hardware currently only supports measurement bandwidths up to a maximum of 5 GHz (using bandwidth extension options) . Thus, measurements with 3 or 4 channels can only be performed on data from input files or using downsampling (see method RsFsw.applications.k9X11Ad.configure.edmg.crate.set() ) .

Parameters:

ncb – 1 | 2 | 3 | 4

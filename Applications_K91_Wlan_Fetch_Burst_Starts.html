# FETCh:BURSt:STARts
value: str = driver.applications.k91Wlan.fetch.burst.starts.get()

Returns the start position of each analyzed PPDU in the current capture buffer.

Returns:

position: Comma-separated list of sample numbers indicating the start position of each PPDU. Tip: To obtain the result in seconds, divide the sample number by the input sample rate. This value is indicated as Sample Rate Fs in the channel bar.

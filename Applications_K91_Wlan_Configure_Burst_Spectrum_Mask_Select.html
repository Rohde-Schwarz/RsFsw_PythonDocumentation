# CONFigure:BURSt:SPECtrum:MASK:SELect
# get:
value: enums.SpectrumMaskStandard = driver.applications.k91Wlan.configure.burst.spectrum.mask.select.get()
# set:
driver.applications.k91Wlan.configure.burst.spectrum.mask.select.set(standard = enums.SpectrumMaskStandard.ETSI)

Sets the Spectrum Emission Mask (SEM) measurement type.

Parameters:

standard – IEEE | ETSI | User

  • User: Settings and limits are configured via a user-defined XML file. Load the file using MMEMory:LOAD:SEM:STATe.

  • IEEE: Settings and limits are as specified in the IEEE Std 802.11n™-2009 Figure 20-17—Transmit spectral mask for 20 MHz transmission. For other IEEE standards see the parameter values in the table below.After a query, IEEE is returned for all IEEE standards.

  • ETSI: Settings and limits are as specified in the ETSI standard.

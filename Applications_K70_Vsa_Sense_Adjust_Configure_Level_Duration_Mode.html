# [SENSe]:ADJust:CONFigure[:LEVel]:DURation:MODE
# get:
value: enums.AutoManualMode = driver.applications.k70Vsa.sense.adjust.configure.level.duration.mode.get()
# set:
driver.applications.k70Vsa.sense.adjust.configure.level.duration.mode.set(auto_auto_level = enums.AutoManualMode.AUTO)

To determine the ideal reference level, the FSW performs a measurement on the current input data. This command selects the way the FSW determines the length of the measurement .

Parameters:

auto_auto_level –

  • AUTO: The FSW determines the measurement length automatically according to the current input data.

  • MANual: The FSW uses the measurement length defined by [SENSe:]ADJust:CONFigure:LEVel:DURation.

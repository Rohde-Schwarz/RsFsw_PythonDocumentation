# DIAGnostic:HUMS:SYSTem:STATus:SUMMary
value: enums.SystemStatus = driver.diagnostic.hums.system.status.summary.get()

Queries the status summary of the complete system.

Returns:

system_status:

  • OK: The system is OK.

  • WARNing: There are some issues with the system which might be critical later.

  • ERRor: Problems with the system occurred and the status is critical.

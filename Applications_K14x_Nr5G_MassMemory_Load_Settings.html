# MMEMory:LOAD:SETTings
# set:
driver.applications.k14Xnr5G.massMemory.load.settings.set()
# set_with_opc:
driver.applications.k14Xnr5G.massMemory.load.settings.set_with_opc(opc_timeout_ms = 3000)

Restores the settings of the last measurement sequence in combined mode.

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsFsw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.

# [SENSe]:NR5G:RSUMmary:SHOW
# get:
value: enums.SummaryMode = driver.applications.k14Xnr5G.sense.nr5G.rsummary.show.get()
# set:
driver.applications.k14Xnr5G.sense.nr5G.rsummary.show.set(result = enums.SummaryMode.AVERage)

Selects the way the contents of the result summary are calculated.

Parameters:

result –

  • AVERage: Shows the average over all analyzed frames.

  • SINGle: Shows the result for the frame selected with [SENSe:]NR5G[:CCcc]:FRAMe:SELect.If only one frame has been captured, the results are the same in both cases.
